# CHOCCS

**CHOCCS: A Deep Learning Tool for Predicting Collision Cross Sections of Carbohydrates and Their Derivatives**

CHOCCS is a deep learning-based software tool developed for predicting ion mobility collision cross sections (CCS) of carbohydrates and their derivatives. It integrates molecular physicochemical descriptors, structural fingerprints, and graph-based molecular representations to provide accurate CCS predictions.

CHOCCS is designed to facilitate ion mobility–mass spectrometry (IM–MS) data interpretation, support molecular identification, and assist in the structural annotation of carbohydrates and related compounds.

1. Download the CHOCCS RAR archive from the [Releases page](https://github.com/BaiYCLab/CHOCCS/releases).
2. Extract the archive using WinRAR, 7-Zip, or another compatible extraction tool.
3. Open the extracted folder.
4. Locate and launch `CHOCCS.exe`.

The packaged executable is intended for use without manually installing a Python environment or deep learning dependencies.

## Usage

CHOCCS provides a desktop interface for CCS prediction.

**Step 1. Prepare molecular input data**

Prepare the molecular structures to be analyzed in a format supported by the application. Select the appropriate ion adduct information for the target compounds.

**Step 2. Launch CHOCCS**

Open `CHOCCS.exe` to start the application.

**Step 3. Import molecular data**

Use the application interface to load the prepared molecular input data.

**Step 4. Run CCS prediction**

Configure the required prediction options and execute the prediction workflow. CHOCCS processes molecular information and generates predicted CCS values for the selected compounds and adducts.

**Step 5. Examine prediction results**

Review the predicted CCS values and export the results using the options available in the application. The predictions can be used to support experimental IM–MS data interpretation and candidate structure prioritization.

## Applications

CHOCCS can be used for:

- CCS prediction for carbohydrates and their derivatives.
- Supporting carbohydrate annotation in complex biological samples.
- Comparing predicted and experimentally measured CCS values.
- Prioritizing candidate molecular structures in IM–MS-based analyses.
- Facilitating metabolomics and glycomics research.
